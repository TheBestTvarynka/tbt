# AI Policy

- Using AI (i.e., LLMs) as tools for writing is only allowed for spelling and punctuation corrections.
- AI is **not allowed** for producing any kind of content on this blog.
  The content term refers to the blog post text (descriptions, explanations, thoughts, opinions, title), schemes and diagrams, images.
- AI may only be used for generating mock images, text placeholders (like fake names), test data, code examples.
  All generated code examples and test data **must be reviewed** by the author.
